360 Docs

A document editor with saved pages, comments, sharing, and basic rich text tools.

Overview

360 Docs is the document editor in the 360 app collection. It provides a browser-based workspace for writing and saving documents.

Editing

The editor includes basic formatting controls such as headings, normal text, lists, links, and copy actions.

Pages

Documents can contain multiple pages. New pages can be added from the page controls.

Sharing

The app includes share and comment controls for working with documents.

Saving

Use Save after making changes. Sign-in controls are available from the app navigation.

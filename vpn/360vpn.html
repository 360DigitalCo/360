PAC File Setup GuideDetecting OS…
PAC URL https://360-search.com/vpn/proxy.pac
  1. Press Win + I to open Settings, then go to Network & Internet → Proxy.
  2. Scroll to "Use setup script" and toggle it On.
  3. Paste the PAC URL into the Script address field: https://360-search.com/vpn/proxy.pac
  4. Click Save. The setting applies immediately to all apps that use the system proxy.
  5. To verify: open a browser, visit http://httpbin.org/ip — the IP shown should match your worker's egress.
  1. Open System Settings → Network → select your active interface (Wi-Fi or Ethernet) → click Details…
  2. Go to the Proxies tab.
  3. Check "Automatic Proxy Configuration".
  4. Enter the PAC URL: https://360-search.com/vpn/proxy.pac
  5. Click OK then Apply. Repeat for other interfaces if needed.
  6. macOS caches PAC files aggressively. To flush: run sudo killall -HUP mDNSResponder in Terminal.
  1. Open Settings → Wi-Fi → tap the ⓘ next to your network.
  2. Scroll down to HTTP Proxy → tap Configure Proxy.
  3. Select Automatic.
  4. Enter the PAC URL: https://360-search.com/vpn/proxy.pac
  5. Tap Save. This applies only to the selected Wi-Fi network. Repeat for other networks.
  6. Note: iOS does not support PAC on cellular data — only Wi-Fi.
  1. Open Settings → Wi-Fi → long-press your network → Modify network.
  2. Tap Advanced options → set Proxy to Proxy Auto-Config.
  3. Enter the PAC URL: https://360-search.com/vpn/proxy.pac
  4. Tap Save. Android applies the PAC only to that Wi-Fi network.
  5. On newer Android/Samsung you may see PAC URL directly — paste the URL there.
  1. GNOME: Settings → Network → Network Proxy → set Method to Automatic → enter the PAC URL.
  2. KDE: System Settings → Network → Proxy → select Use proxy auto-configuration URL → enter the PAC URL.
  3. System-wide / CLI: Add to /etc/environment: auto_proxy=https://360-search.com/vpn/proxy.pac
  4. For curl / apt / wget, set https_proxy instead — PAC files are not supported natively by these tools. Use the proxy endpoint directly: https://360-search.com/vpn/proxy
  5. Restart the network manager or log out and back in for changes to take effect.
  1. Click the system tray clock → Settings → Network → click your Wi-Fi or Ethernet connection.
  2. Click the gear icon next to the network name.
  3. Go to the Proxy tab → select Automatic proxy configuration.
  4. Enter the PAC URL: https://360-search.com/vpn/proxy.pac
  5. Click Save. ChromeOS applies the proxy to all network traffic on that connection.
  1. In Firefox, open about:preferences → scroll to Network Settings → click Settings…
  2. Select "Automatic proxy configuration URL".
  3. Paste: https://360-search.com/vpn/proxy.pac
  4. Click OK. Firefox uses its own proxy settings independently from the OS.
  5. To force reload: open about:config → search network.proxy.autoconfig_url → confirm the URL is correct.
